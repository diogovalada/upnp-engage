# Changelog

## v0.1.0

First versioned release of UPnP Engage.

- Enter your ports on first launch, optionally save them, and start automatically from a saved config next time.
- Copy the external address to share with friends, or change ports while the program is open.
- Windows and Linux x86_64 builds, plus native macOS builds for Apple Silicon and Intel.
- Coordinated shutdown cleanup, partial-start rollback, and renewed one-hour forwarding leases.

Download the Windows `.exe`, Linux executable, or the ZIP for your Mac. The Mac ZIP contains one executable; extract it and double-click `upnp-engage.command`. Mac builds are not Developer ID signed or notarized: after the first blocked launch, use **System Settings → Privacy & Security → Open Anyway** if you trust the download.

See the [README](https://github.com/diogovalada/upnp-engage#readme) for setup and troubleshooting. The displayed address is supplied by your router; internet reachability is not tested. Live-router and full desktop launch checks remain manual.
